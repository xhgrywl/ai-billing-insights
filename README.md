# AI 账单洞察助手

一个无需安装依赖、可直接在浏览器运行的前端原型。系统提供普通用户和管理员两类工作台，支持新增账单、查看分类统计，并根据账单结构生成消费洞察与节支建议。

## 功能

- 普通用户和管理员两类身份入口
- 本月支出、预算与结余概览
- 新增账单与账单列表
- 分类占比和近七日趋势
- 基于账单数据的 AI 洞察建议
- 管理员查看全站用户与反馈概览

## 运行方式

双击打开 `index.html`，或在项目目录运行静态服务器后访问该页面。

## 演示流程

1. 以普通用户身份进入仪表盘
2. 新增一笔餐饮或交通账单
3. 点击“生成 AI 消费洞察”查看分析结果
4. 切换到管理员身份，查看平台概览和反馈列表

## 技术说明

项目使用 HTML、CSS 和原生 JavaScript 构建。账单数据保存在浏览器本地存储中，AI 洞察模块根据金额、类别和预算比例生成可解释的建议，方便后续替换为真实大模型接口。
